2. 手動 RAM 測試

CURRENT = 61 bytes；候選 = 62 bytes。descriptor 必須恰好匹配；不符就停止，不補零、不截斷。

每次只對選定取樣率送出 9 段係數（其他段設 flat），再啟用既有 mode 0，共 10 個封包。這不是九段功能驗證。

單段設定：第 1 段 PK / 1000 Hz / −12 dB / Q 0.7；其餘 8 段 0 dB。兩次比較維持相同 framing、取樣率、來源及音量。
